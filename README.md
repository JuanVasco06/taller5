# Workshop #5 - Doubly Linked List

## Author

Juan Pablo Vasco Orjuela

## Description

This project implements a generic doubly linked list in C# using a console application developed in Visual Studio.

The main objective of this workshop is to demonstrate the understanding and implementation of linked lists, specifically a doubly linked list where each node contains a reference to the previous node and the next node.

The list allows the user to insert elements, display them in both directions, sort the list in descending order, calculate the mode, display an occurrence graph, search for an element, and delete one or all occurrences of a value.
